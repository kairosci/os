# Arch käytössä...

### Apple M1/M2 -sirut

[Asahi Alarm](https://asahi-alarm.org/) on versio Archista Apple M1/M2 -tietokoneille, rakennettu [Asahi Linuxin](https://asahilinux.org/) päälle. Saat Archn toimimaan sen päällä hieman vaivaa nähden. Katso [käyttäjien tekemää opasta](https://github.com/kairosci/os).

### Apple-virtuaalikone

Voit asentaa Archn myös Parallels VM:ään. Melko työläs prosessi, mutta siihenkin on [käyttäjien tekemä opas](https://github.com/kairosci/os).

### VirtualBox

VirtualBox on suosittu VM-ajuri. [Voit ajaa Archn myös siinä](https://github.com/kairosci/os). Mutta suorituskyky ei todennäköisesti ole hääppöinen.

### VMware Workstation Windows 11:ssä

Toinen suosittu VM-ajuri Windowsille. [Arch on asetettu myös sen sisään](https://github.com/kairosci/os).

### Steam Deck

Steam Deck toimii Archilla, mikä tarkoittaa, että voit ajaa Archn Steam Deckilläsi. Altynbek Orumbayevilla on [koko asennusskripti ja selitys, miten se tehdään](https://github.com/aorumbayev/deckarchy). Kuinka hienoa se onkaan!

### NixOS

Arch on oikeastaan Arch + Hyprland, mutta Henry Sipp on [siirtänyt asennuksen ytimen NixOS:ään](https://github.com/henrysipp/arch-nix). Joten jos olet ottanut nix-pillerin, tässä on hyvä lähtökohta. Se ei välttämättä pysy ajan tasalla uusimpien Arch-muutosten kanssa, mutta se on silti aika hienoa!

### Jotain muuta!

Jos yrität saada Archn toimimaan kokoonpanolla, joka ei ole oletus, sinun kannattaa liittyä #arch-on-other-kanavalle [yhteisömme Discordissa](https://discord.gg/tXFUdasqhY).
