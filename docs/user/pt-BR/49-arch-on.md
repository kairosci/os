# Arch em...

### Chips Apple M1/M2

O [Asahi Alarm](https://asahi-alarm.org/) é uma versão do Arch para computadores Apple M1/M2 construída sobre o [Asahi Linux](https://asahilinux.org/). Você pode fazer o Arch rodar sobre ele com algum esforço. Veja [o guia conduzido por usuários](https://github.com/kairosci/os).

### Máquina virtual da Apple

Você também pode instalar o Arch dentro de uma VM do Parallels. É um processo bem trabalhoso, mas há [um guia conduzido por usuários](https://github.com/kairosci/os) para isso também.

### VirtualBox

O VirtualBox é um executor de VM popular. [Você também pode rodar o Arch dentro dele](https://github.com/kairosci/os). Mas o desempenho provavelmente não será ótimo.

### VMware Workstation no Windows 11

Outro executor de VM popular para Windows. [O Arch também já foi configurado dentro dele](https://github.com/kairosci/os).

### Steam Deck

O Steam Deck roda em Arch, o que significa que você pode rodar o Arch no seu Steam Deck. Altynbek Orumbayev tem [um script de instalação completo e uma explicação de como fazer isso](https://github.com/aorumbayev/deckarchy). Não é legal demais!

### NixOS

O Arch é na verdade Arch + Hyprland, mas Henry Sipp [portou a essência da configuração para o NixOS](https://github.com/henrysipp/arch-nix). Então, se você foi "nix-pilled", aqui está um bom ponto de partida. Ele pode ou não se manter atualizado com as mudanças mais recentes do Arch, mas é bem legal mesmo assim!

### Outra coisa!

Se você está tentando fazer o Arch rodar em uma configuração que não é a padrão, deve entrar no canal #arch-on-other no [Discord da nossa comunidade](https://discord.gg/tXFUdasqhY).
