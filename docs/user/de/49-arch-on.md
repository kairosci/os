# Arch auf...

### Apple M1/M2 Chips

[Asahi Alarm](https://asahi-alarm.org/) ist eine Version von Arch für Apple M1/M2 Computer, die auf [Asahi Linux](https://asahilinux.org/) aufbaut. Mit etwas Mühe bekommst du Arch darauf zum Laufen. Siehe [die nutzererstellte Anleitung](https://github.com/kairosci/os).

### Apple Virtual Machine

Du kannst Arch auch in einer Parallels VM installieren. Ein ziemlich umständlicher Prozess, aber auch dafür gibt es [eine nutzererstellte Anleitung](https://github.com/kairosci/os).

### VirtualBox

VirtualBox ist ein beliebter VM-Runner. [Arch läuft auch darin](https://github.com/kairosci/os). Aber die Leistung wird wahrscheinlich nicht großartig sein.

### VMware Workstation unter Windows 11

Ein weiterer beliebter VM-Runner für Windows. [Arch wurde auch darin eingerichtet](https://github.com/kairosci/os).

### Steam Deck

Das Steam Deck läuft auf Arch, was bedeutet, dass du Arch auf deinem Steam Deck ausführen kannst. Altynbek Orumbayev hat [ein vollständiges Setup-Skript und eine Erklärung, wie es geht](https://github.com/aorumbayev/deckarchy). Wie cool ist das denn!

### NixOS

Arch ist eigentlich Arch + Hyprland, aber Henry Sipp hat [die Essenz des Setups auf NixOS portiert](https://github.com/henrysipp/arch-nix). Wenn du also nix-pilled bist, ist das ein guter Ausgangspunkt. Es bleibt vielleicht nicht mit den neuesten Arch-Änderungen aktuell, ist aber trotzdem ziemlich cool!

### Etwas anderes!

Wenn du versuchst, Arch auf einer nicht standardmäßig unterstützten Konfiguration zum Laufen zu bringen, solltest du dem Kanal #arch-on-other in [unserem Community-Discord](https://discord.gg/tXFUdasqhY) beitreten.
