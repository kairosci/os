# Arch di...

### Chip Apple M1/M2

[Asahi Alarm](https://asahi-alarm.org/) adalah versi Arch untuk komputer Apple M1/M2 yang dibangun di atas [Asahi Linux](https://asahilinux.org/). Kamu bisa menjalankan Arch di atasnya dengan sedikit usaha. Lihat [panduan dari pengguna](https://github.com/kairosci/arch).

### Mesin Virtual Apple

Kamu juga bisa memasang Arch di dalam VM Parallels. Prosesnya cukup merepotkan, tetapi ada juga [panduan dari pengguna](https://github.com/kairosci/arch) untuk itu.

### VirtualBox

VirtualBox adalah runner VM yang populer. [Kamu juga bisa menjalankan Arch di dalamnya](https://github.com/kairosci/arch). Tetapi performanya mungkin tidak akan hebat.

### VMware Workstation di Windows 11

Runner VM populer lainnya untuk Windows. [Arch juga telah diatur di dalamnya](https://github.com/kairosci/arch).

### Steam Deck

Steam Deck berjalan pada Arch, yang berarti kamu bisa menjalankan Arch di Steam Deck kamu. Altynbek Orumbayev memiliki [skrip pengaturan lengkap dan penjelasan tentang cara melakukannya](https://github.com/aorumbayev/deckarchy). Bukankah itu keren!

### NixOS

Arch sebenarnya adalah Arch + Hyprland, tetapi Henry Sipp telah [memindahkan inti pengaturannya ke NixOS](https://github.com/henrysipp/arch-nix). Jadi jika kamu sudah terpengaruh nix, ini adalah titik awal yang bagus. Ia mungkin atau mungkin tidak tetap mutakhir dengan perubahan Arch terbaru, tetapi ini cukup keren bagaimanapun juga!

### Sesuatu yang lain!

Jika kamu mencoba menjalankan Arch pada konfigurasi yang bukan bawaan, kamu harus bergabung dengan kanal #arch-on-other di [Discord komunitas](https://discord.gg/tXFUdasqhY) kami.
