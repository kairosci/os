# Arch ...-এ

### Apple M1/M2 চিপ

[Asahi Alarm](https://asahi-alarm.org/) হলো [Asahi Linux](https://asahilinux.org/)-এর উপর তৈরি Apple M1/M2 কম্পিউটারের জন্য Arch-এর একটি সংস্করণ। কিছু প্রচেষ্টায় তার উপর Arch চালাতে পারেন। [ব্যবহারকারী-চালিত গাইড](https://github.com/kairosci/os) দেখুন।

### Apple Virtual Machine

Parallels VM-এর ভেতরেও Arch ইনস্টল করতে পারেন। বেশ ঝামেলার প্রক্রিয়া, কিন্তু তার জন্যও [একটি ব্যবহারকারী-চালিত গাইড](https://github.com/kairosci/os) আছে।

### VirtualBox

VirtualBox একটি জনপ্রিয় VM রানার। [তার ভেতরেও Arch চালাতে পারেন](https://github.com/kairosci/os)। কিন্তু পারফরম্যান্স সম্ভবত দুর্দান্ত হবে না।

### Windows 11-এ VMware Workstation

Windows-এর জন্য আরেকটি জনপ্রিয় VM রানার। [Arch তার ভেতরেও সেটআপ করা হয়েছে](https://github.com/kairosci/os)।

### Steam Deck

Steam Deck Arch-এ চলে, যার অর্থ আপনি আপনার Steam Deck-এ Arch চালাতে পারেন। Altynbek Orumbayev-এর [কীভাবে করতে হবে তার সম্পূর্ণ সেটআপ স্ক্রিপ্ট ও ব্যাখ্যা](https://github.com/aorumbayev/deckarchy) আছে। কত দারুণ ব্যাপার!

### NixOS

Arch আসলে Arch + Hyprland, কিন্তু Henry Sipp [সেটআপের সারাংশ NixOS-এ পোর্ট করেছেন](https://github.com/henrysipp/arch-nix)। তাই আপনি nix-pilled হয়ে থাকলে, এখানে একটি ভালো সূচনা বিন্দু আছে। এটি সর্বশেষ Arch পরিবর্তনের সাথে হালনাগাদ থাকতে পারে বা নাও পারে, কিন্তু তবু বেশ দারুণ!

### অন্য কিছু!

ডিফল্ট নয় এমন কনফিগারেশনে Arch চালানোর চেষ্টা করলে, [আমাদের কমিউনিটি Discord](https://discord.gg/tXFUdasqhY)-এ #arch-on-other চ্যানেলে যোগ দেওয়া উচিত।
