# การนำทาง

ทุกอย่างใน Arch เกิดขึ้นผ่านคีย์บอร์ด — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณทำอะไรด้วยเมาส์เพียงอย่างเดียวไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Arch Menu ได้ และจากตรงนี้คุณก็ทำได้แทบทุกอย่าง

แต่เมนู Arch ไม่ได้ถูกตั้งใจให้เป็นวิธีหลักในการใช้งานระบบในเวลาส่วนใหญ่เลยด้วยซ้ำ เราไปได้เร็วกว่านั้น! แอปพลิเคชันที่สำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดแต่ละปุ่มโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอันหนึ่งต่ออีกอันหนึ่ง แล้วคุณจะเห็นความมหัศจรรย์ของการจัดเรียงแบบ tiling ของ Hyprland ทำงานจริง:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อวางพวกมันซ้อนกันแทนที่จะอยู่ข้าง ๆ กันได้:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อนำพวกมันกลับไปอยู่ข้าง ๆ กันเหมือนเดิม จากนั้นลองกด `Super + Shift + Arrow Right` ขณะอยู่บนเบราว์เซอร์เพื่อสลับหน้าต่างทั้งสอง

ตอนนี้ลองกด `Super + Ctrl + T` เพื่อเปิดตัวตรวจสอบกิจกรรม มันจะปรากฏเป็นหน้าต่างแบบลอยตัว คุณสามารถทำให้มันเป็นแบบ tiling ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันกลับไปลอยตัวอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางแบบสี่ส่วนที่เรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณเลื่อนไปยังหน้าต่างที่ต้องการให้ทำงานอยู่ด้วย `Super + Arrow` การทำเช่นนี้จะเปลี่ยนโฟกัสและย้ายเคอร์เซอร์ไปยังกลางแอปพลิเคชันใหม่

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สอง `Super + Shift + 1` จะย้ายมันกลับมา (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สองโดยไม่สลับตามไป)

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกที่หน้าต่าง คุณจะจัดตำแหน่งที่มันอยู่ใหม่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาของเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังเข้าสู่โหมดเต็มหน้าจอด้วย `Super + F` หรือแค่เต็มความกว้าง (โดยยังเก็บแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะมากสำหรับ YouTube!) ได้อีกด้วย

### เลย์เอาต์ Dwindle กับเลย์เอาต์แบบเลื่อน

เลย์เอาต์เริ่มต้นของ Arch เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนเวิร์กสเปซเดียวมองเห็นได้ตลอดเวลา แม้จะต้องย่อพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังเลือกเปลี่ยนเวิร์กสเปซให้เป็นเลย์เอาต์แบบเลื่อนได้เช่นกัน โดยหน้าต่างต่าง ๆ จะเรียงกันข้าง ๆ กันเลยขอบที่มองเห็นของหน้าจอออกไป คุณเปลี่ยนเวิร์กสเปซเดียวให้เป็นเลย์เอาต์นี้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนเวิร์กสเปซให้เป็นแบบลอยตัว ซึ่งหน้าต่างต่าง ๆ จะซ้อนทับกันอย่างอิสระและคุณจัดวางพวกมันด้วยตัวเอง และการกดครั้งที่สามจะนำมันกลับไปเป็น dwindle `Super + Alt + L` จะวนไปในทิศทางตรงกันข้าม หน้าต่างที่ลอยตัวอยู่แล้ว — หน้าต่างที่คุณดึงออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยตัวเสมอ — จะยังคงลอยตัวอยู่เมื่อเวิร์กสเปซกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายเวิร์กสเปซที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมสำหรับ dwindle วงกลมสำหรับแบบเลื่อน และสามเหลี่ยมสำหรับแบบลอยตัว การคลิกที่เครื่องหมายนั้นจะวนเปลี่ยนเลย์เอาต์ได้เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

ตัวเลือกนี้เป็นแบบแยกตามเวิร์กสเปซ และมันจะคงอยู่ ดังนั้นคุณสามารถให้เวิร์กสเปซ 1 อยู่บน dwindle สำหรับการท่องเว็บ และเวิร์กสเปซ 2 อยู่บนแบบเลื่อนสำหรับโค้ดได้ และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

ถ้าคุณต้องการใช้เลย์เอาต์แบบเลื่อนเป็นค่าเริ่มต้น คุณสามารถตั้งค่านั้นได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### การจัดกลุ่มหน้าต่าง

หน้าต่างต่าง ๆ สามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว ทุกหน้าต่างที่คุณเปิดในขณะที่กลุ่มนั้นกำลังทำงานอยู่จะอยู่ในกลุ่มนั้น คุณสามารถเลื่อนไปมาระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้ได้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มได้ด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดออกจากกันโดยการกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างที่อยู่นอกกลุ่มเข้ามาในกลุ่มได้ด้วย `Super + Alt + Arrows`

### เวิร์กสเปซ Scratchpad

สุดท้าย มีเวิร์กสเปซ scratchpad พิเศษที่จะเลื่อนลงมาทับเวิร์กสเปซใดก็ตามที่คุณกำลังอยู่ คล้ายกับคอนโซลใน Quake สลับมันด้วย `Super + Grave` หรือ `Super + S` และวางหน้าต่างไว้ตรงนั้นโดยใช้ `Super + Shift + Grave` หรือ `Super + Alt + S`

มันทำงานได้ดีเป็นพิเศษสำหรับเทอร์มินัลที่กำลังรัน agent อยู่ หรือสำหรับตัวควบคุมต่าง ๆ ที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากเวิร์กสเปซปัจจุบัน ในการย้ายหน้าต่างออกจาก scratchpad ให้ส่งมันไปยังเวิร์กสเปซอื่นโดยตรงด้วยอะไรอย่างเช่น `Super + Shift + 1`

ในขณะที่ scratchpad มีหน้าต่างเดียวอยู่ มันจะเลื่อนลงมาเป็นแผงที่อยู่ตรงกลาง แทนที่จะทอดเต็มหน้าจอ ใส่แอปที่สองเข้าไปแล้วมันจะกลับไปเป็นความกว้างเต็มที่ เพื่อให้ทั้งสองมีพื้นที่อยู่ข้าง ๆ กัน

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักเล็กน้อยในการทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปใช้ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
