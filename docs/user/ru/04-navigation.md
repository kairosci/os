# Навигация

Всё в Arch происходит с клавиатуры — _ВСЁ!_ Когда система только запускается, одной мышью вы буквально ничего не сможете сделать. Но вы можете нажать `Super + Space`, чтобы открыть меню Arch, а уже оттуда делать практически всё.

Но меню Arch даже не задумывалось как основной способ работы с системой в большинстве случаев. Можно быстрее! Все самые важные приложения привязаны прямо к отдельным горячим клавишам. Терминал запускается по `Super + Return`, а браузер — по `Super + Shift + Return`. Попробуйте сделать одно за другим, и вы увидите волшебство плиточной раскладки Hyprland в действии:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

Затем вы можете нажать `Super + J`, чтобы расположить их друг над другом, а не рядом:

 ![navigation-stacked](images/navigation-stacked.webp)

Нажмите `Super + J` ещё раз, чтобы вернуть их в положение рядом друг с другом. Затем попробуйте `Super + Shift + Arrow Right`, находясь в браузере, чтобы поменять окна местами.

Теперь попробуйте `Super + Ctrl + T`, чтобы запустить монитор активности. Он появится как плавающее окно. Вы можете сделать его плиточным с помощью `Super + T` (и нажать это ещё раз, чтобы снова сделать его плавающим). Теперь нажмите `Super + Shift + F`, чтобы открыть файловый менеджер. У вас получится аккуратная раскладка на четыре окна:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

Между окнами вы переключаетесь на то, которое хотите сделать активным, с помощью `Super + Arrow`. Это переключит фокус и переместит курсор в центр нового приложения.

Если вы нажмёте `Super + Shift + 2`, вы переместите текущее приложение в фокусе на второе рабочее пространство. `Super + Shift + 1` вернёт его обратно. (А `Super + Shift + Alt + 2` переместит текущее приложение в фокусе на второе рабочее пространство, не переключаясь на него).

Если вы удерживаете `Super` и щёлкаете мышью по окну, вы сможете переставить его туда, где оно должно находиться. Если вы удерживаете `Super` и используете правую кнопку мыши, вы можете свободно менять размер окна.

Окно закрывается по `Super + W` или `Super + Q` (а все окна — по `Ctrl + Alt + Delete`).

Вы также можете развернуться на весь экран с помощью `Super + F` или даже просто на всю ширину (сохранив верхнюю панель) с помощью `Super + Alt + F`, или на весь экран внутри окна с помощью `Super + Ctrl + F` (хорошо для YouTube!).

### Раскладка dwindle против прокручиваемой раскладки

Раскладка Arch по умолчанию называется dwindle. Она держит все окна, которые вы открываете на одном рабочем пространстве, видимыми всё время, даже если для этого их приходится уменьшать.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

Но вы также можете превратить рабочее пространство в прокручиваемую раскладку, где окна выстроены рядом друг с другом за видимым краем дисплея. Одно рабочее пространство превращается в эту раскладку с помощью `Super + L`.

Повторное нажатие `Super + L` делает рабочее пространство плавающим, где окна свободно перекрываются и вы размещаете их сами, а третье нажатие возвращает его к dwindle. `Super + Alt + L` проходит по ним в обратную сторону. Окно, которое и так плавает — то, которое вы вынули с помощью `Super + T`, или приложение, которое всегда открывается плавающим, — продолжает плавать, когда рабочее пространство возвращается к плиточной раскладке. Верхняя панель отмечает рабочее пространство, на котором вы находитесь, его раскладкой: квадрат для dwindle, круг для прокручиваемой и треугольник для плавающей. Щелчок по этой отметке тоже переключает раскладку по кругу.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

Выбор делается для каждого рабочего пространства отдельно, и он сохраняется. Так что вы можете держать рабочее пространство 1 на dwindle для браузера, а рабочее пространство 2 на прокручиваемой раскладке для кода, и после перезапуска они вернутся именно такими.

Если вы хотите использовать прокручиваемую раскладку по умолчанию, вы можете задать это в `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Группировка окон

Окна можно группировать с помощью `Super + G`. Когда вы находитесь в группе, каждое окно, которое вы запустите, пока она активна, будет принадлежать к группе. Вы можете перемещаться между этими сгруппированными окнами с помощью `Super + Ctrl + Arrow Left/Right` или `Super + Alt + 1/2/3/4`, чтобы перейти прямо к сгруппированному окну по порядку.

Вы можете переместить окно из группировки с помощью `Super + Alt + G` или разобрать всю группу, снова нажав `Super + G`. Наконец, вы можете перемещать окна снаружи группы в неё с помощью `Super + Alt + Arrows`.

### Рабочее пространство scratchpad

Наконец, есть специальное рабочее пространство scratchpad, которое опускается поверх любого рабочего пространства, на котором вы сейчас находитесь, очень похоже на консоль Quake. Переключайте его с помощью `Super + Grave` или `Super + S`, а окно туда помещайте с помощью `Super + Shift + Grave` или `Super + Alt + S`.

Оно особенно хорошо подходит для терминала с работающим агентом или для элементов управления, с которыми вы хотите быстро взаимодействовать, не покидая текущее рабочее пространство. Чтобы убрать окно со scratchpad, отправьте его прямо на другое рабочее пространство чем-то вроде `Super + Shift + 1`.

Пока на scratchpad находится одно окно, он опускается как панель по центру, а не растягивается на весь экран. Поместите на него второе приложение, и он вернётся к полной ширине, чтобы у двоих было место сидеть рядом.

### К этому нужно немного привыкнуть!

Нужно немного времени, чтобы привыкнуть так перемещаться по рабочему столу, но как только вы привыкнете, вернуться к традиционному опыту рабочего стола, управляемого мышью, будет трудно!
