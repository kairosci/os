# Arch op...

### Apple M1/M2-chips

[Asahi Alarm](https://asahi-alarm.org/) is een versie van Arch voor Apple M1/M2-computers gebouwd bovenop [Asahi Linux](https://asahilinux.org/). Je kunt Arch daar bovenop aan de praat krijgen met enige moeite. Zie [de door gebruikers gedreven gids](https://github.com/kairosci/os).

### Apple Virtual Machine

Je kunt Arch ook installeren in een Parallels VM. Een behoorlijk omslachtig proces, maar daar is ook [een door gebruikers gedreven gids](https://github.com/kairosci/os) voor.

### VirtualBox

VirtualBox is een populaire VM-runner. [Je kunt Arch daar ook in draaien](https://github.com/kairosci/os). Maar de prestaties zullen waarschijnlijk niet geweldig zijn.

### VMware Workstation op Windows 11

Nog een populaire VM-runner voor Windows. [Arch is daar ook in opgezet](https://github.com/kairosci/os).

### Steam Deck

De Steam Deck draait op Arch, wat betekent dat je Arch op je Steam Deck kunt draaien. Altynbek Orumbayev heeft [een volledig setupscript en uitleg over hoe je het doet](https://github.com/aorumbayev/deckarchy). Hoe cool is dat!

### NixOS

Arch is eigenlijk Arch + Hyprland, maar Henry Sipp heeft [de essentie van de setup geport naar NixOS](https://github.com/henrysipp/arch-nix). Dus als je nix-pilled bent, is dit een goed startpunt. Het kan al dan niet up-to-date blijven met de nieuwste Arch-wijzigingen, maar het is hoe dan ook behoorlijk cool!

### Iets anders!

Als je Arch draaiende probeert te krijgen op een configuratie die niet de standaard is, moet je lid worden van het #arch-on-other-kanaal op [onze community-Discord](https://discord.gg/tXFUdasqhY).
