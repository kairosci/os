# Arrière-plans

Chaque thème est livré avec son propre jeu d'arrière-plans, et vous pouvez en ajouter dans `~/.config/arch/backgrounds/[theme]`. Si vous voulez ajouter une image d'arrière-plan supplémentaire au thème nord, par exemple, placez simplement le fichier dans `~/.config/arch/backgrounds/nord`.

Le plus simple est d'aller dans _Installer > Style > Arrière-plan_ dans le menu Arch. Cela ouvrira le dossier où sont stockés les arrière-plans de ce thème. Appuyez sur `Super + Shift + F` pour lancer un autre gestionnaire de fichiers, trouvez votre arrière-plan, copiez-le. Il figurera désormais parmi les arrière-plans entre lesquels vous pouvez choisir avec `Super + Ctrl + Space`.

Les arrière-plans peuvent être des vidéos ou des images fixes. Déposez un fichier `mp4`, `m4v`, `mov`, `webm`, `mkv` ou `avi` dans le même dossier pour le voir à côté des images. Les vidéos utilisent le lecteur Qt Multimedia intégré à Arch, s’arrêtent lorsqu’elles sont masquées ou couvertes et restent muettes sur l’écran de verrouillage. Un fond vidéo consomme tout de même bien plus d’énergie qu’une image fixe.



Vous pouvez trouver une immense collection d'arrière-plans curatés et sympas sur https://github.com/dharmx/walls.

Les arrière-plans vidéo gardent une image fixe en cache sur l'écran de verrouillage pendant que la lecture est en pause ou indisponible. Les GIF animés se jouent sur le bureau et affichent une image fixe sur l'écran de verrouillage.
