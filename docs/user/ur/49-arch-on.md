# Arch پر...

### Apple M1/M2 چپس

[Asahi Alarm](https://asahi-alarm.org/) Apple M1/M2 کمپیوٹرز کے لیے Arch کا ایک ورژن ہے جو [Asahi Linux](https://asahilinux.org/) پر بنا ہے۔ آپ کچھ محنت سے اس کے اوپر Arch چلا سکتے ہیں۔ [صارف کی چلائی ہوئی گائیڈ](https://github.com/kairosci/arch) دیکھیں۔

### Apple ورچوئل مشین

آپ Arch کو Parallels VM کے اندر بھی انسٹال کر سکتے ہیں۔ کافی دشوار عمل ہے، لیکن اس کے لیے بھی [صارف کی چلائی ہوئی گائیڈ](https://github.com/kairosci/arch) موجود ہے۔

### VirtualBox

VirtualBox ایک مقبول VM رنر ہے۔ [آپ اس کے اندر بھی Arch چلا سکتے ہیں](https://github.com/kairosci/arch)۔ لیکن کارکردگی شاید عظیم نہ ہو۔

### Windows 11 پر VMware Workstation

Windows کے لیے ایک اور مقبول VM رنر۔ [Arch اس کے اندر بھی لگایا گیا ہے](https://github.com/kairosci/arch)۔

### Steam Deck

Steam Deck Arch پر چلتا ہے، جس کا مطلب ہے کہ آپ اپنے Steam Deck پر Arch چلا سکتے ہیں۔ Altynbek Orumbayev کے پاس [اسے کرنے کے طریقے پر ایک مکمل سیٹ اپ اسکرپٹ اور وضاحت](https://github.com/aorumbayev/deckarchy) موجود ہے۔ یہ کتنا دلچسپ ہے!

### NixOS

Arch واقعی Arch + Hyprland ہے، لیکن Henry Sipp نے [سیٹ اپ کا جوہر NixOS میں منتقل](https://github.com/henrysipp/arch-nix) کر دیا ہے۔ لہٰذا اگر آپ کو nix کی گولی لگ گئی ہے تو یہاں ایک اچھا ابتدائی نقطہ ہے۔ یہ تازہ ترین Arch تبدیلیوں کے ساتھ تازہ رہ بھی سکتا ہے یا نہیں بھی، لیکن پھر بھی یہ کافی دلچسپ ہے!

### کچھ اور!

اگر آپ Arch کو ایسی کنفگریشن پر چلانے کی کوشش کر رہے ہیں جو طے شدہ نہیں ہے تو آپ کو [ہماری کمیونٹی Discord](https://discord.gg/tXFUdasqhY) پر #arch-on-other چینل میں شامل ہونا چاہیے۔
