# ניווט

הכול ב-Arch קורה דרך המקלדת — _הכול!_ כשהמערכת עולה בפעם הראשונה, ממש אי אפשר לעשות שום דבר עם העכבר בלבד. אבל אפשר ללחוץ על `Super + Space` כדי לחשוף את תפריט Arch, ומכאן אפשר לעשות כמעט הכול.

אבל תפריט Arch אפילו לא נועד להיות הדרך העיקרית להפעיל את המערכת רוב הזמן. אנחנו יכולים להיות מהירים יותר מזה! כל היישומים החשובים ביותר קשורים ישירות למקשי קיצור בודדים. מפעילים את הטרמינל עם `Super + Return` ודפדפן עם `Super + Shift + Return`. נסו לעשות אחד אחרי השני, ותראו את הקסם של הריצוף של Hyprland בפעולה:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

לאחר מכן אפשר ללחוץ על `Super + J` כדי לערום אותם זה על זה במקום זה לצד זה:

 ![navigation-stacked](images/navigation-stacked.webp)

לחצו שוב על `Super + J` כדי להחזיר אותם למקומם זה לצד זה. לאחר מכן נסו `Super + Shift + Arrow Right` כשאתם בדפדפן כדי להחליף בין החלונות.



 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

מנווטים בין החלון שרוצים שיהיה פעיל עם `Super + Arrow`. זה יחליף את המוקד ויזיז את הסמן למרכז היישום החדש.

אם תלחצו על `Super + Shift + 2`, תעבירו את היישום הממוקד הנוכחי לסביבת העבודה השנייה. `Super + Shift + 1` מחזיר אותו. (ו-`Super + Shift + Alt + 2` יעביר את היישום הממוקד הנוכחי לסביבת העבודה השנייה בלי לעבור אליה).

אם תחזיקו את `Super` ותשתמשו בעכבר כדי ללחוץ על חלון, תוכלו לסדר מחדש היכן הוא יושב. אם תחזיקו את `Super` ותשתמשו בלחצן הימני של העכבר, תוכלו לשנות את גודל החלון בחופשיות.

סוגרים חלון עם `Super + W` או `Super + Q` (וסוגרים את כל החלונות עם `Ctrl + Alt + Delete`).

אפשר גם לעבור למסך מלא עם `Super + F` או אפילו רק לרוחב מלא (תוך שמירה על הסרגל העליון) עם `Super + Alt + F` או למסך מלא בתוך חלון עם `Super + Ctrl + F` (טוב ל-YouTube!).

### פריסת dwindle מול פריסת scrolling

פריסת ברירת המחדל של Arch נקראת dwindle. היא שומרת על כל החלונות שפותחים בסביבת עבודה אחת גלויים בכל עת, גם אם היא צריכה לכווץ אותם.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

אבל אפשר גם לבחור להפוך סביבת עבודה לפריסת scrolling, שבה חלונות מסודרים זה לצד זה, מעבר לקצה הגלוי של הצג. הופכים סביבת עבודה אחת לפריסה הזו באמצעות `Super + L`.


 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

הבחירה היא לכל סביבת עבודה, והיא נשמרת. כך אפשר לשמור את סביבת עבודה 1 על dwindle לגלישה ואת סביבת עבודה 2 על scrolling לקוד, והן יחזרו כך אחרי הפעלה מחדש.

אם רוצים להשתמש בפריסת scrolling כברירת המחדל, אפשר להגדיר זאת ב-`~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### קיבוץ חלונות

ניתן לקבץ חלונות באמצעות `Super + G`. ברגע שאתם בקבוצה, כל חלון שתפעילו בזמן שהיא פעילה ישתייך לקבוצה. ניתן לעבור בין החלונות המקובצים האלה באמצעות `Super + Ctrl + Arrow Left/Right` או `Super + Alt + 1/2/3/4` כדי לעבור ישירות לחלון מקובץ לפי הסדר.

ניתן להוציא חלון מהקיבוץ עם `Super + Alt + G` או לפרק את הקבוצה כולה בלחיצה נוספת על `Super + G`. לבסוף, ניתן להכניס חלונות שמחוץ לקבוצה אליה עם `Super + Alt + Arrows`.

### סביבת עבודה של scratchpad

לבסוף, יש סביבת עבודה מיוחדת של scratchpad שיורדת מעל כל סביבת עבודה שעליה אתם נמצאים כרגע, בדומה מאוד לקונסולת Quake. החליפו אותה עם `Super + Grave` או `Super + S`, והציבו שם חלון באמצעות `Super + Shift + Grave` או `Super + Alt + S`.

היא עובדת טוב במיוחד עבור טרמינל שמריץ agent, או עבור בקרים שרוצים לתקשר איתם במהירות בלי לעזוב את סביבת העבודה הנוכחית. כדי להזיז חלון מה-scratchpad, שלחו אותו ישירות לסביבת עבודה אחרת עם משהו כמו `Super + Shift + 1`.

כל עוד ה-scratchpad מחזיק חלון יחיד, הוא יורד כפאנל ממורכז ולא כפרוס על פני המסך. שימו עליו יישום שני והוא חוזר לרוחב המלא, כך שלשניים יש מקום לשבת זה לצד זה.

### צריך קצת להתרגל לזה!

לוקח קצת זמן להתרגל לנווט בשולחן העבודה שלכם כך, אבל ברגע שמתרגלים, יהיה קשה לחזור לחוויית שולחן עבודה מסורתית מונעת-עכבר!
