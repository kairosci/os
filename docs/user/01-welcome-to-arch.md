# Welcome to Arch!

Arch is a focused Linux desktop built on Arch Linux, the tiling window manager [Hyprland](https://hypr.land/), and [Quickshell](https://quickshell.org/). It provides an efficient workspace for everyday tasks, software development, and communication.

It combines a tiling desktop, a keyboard-focused workflow, and a small set of useful applications. You can add the software you need through the Arch package repositories.

The desktop keeps windows tiled and puts common actions close to the keyboard. Settings, applications, and system tools are available from the Arch menu.

Arch uses Linux and standard Arch configuration files. The terminal is available for commands and development work, while the desktop provides graphical controls for everyday settings.
