# 탐색

Arch에서는 모든 일이 키보드로 이루어진다 — _전부 다!_ 시스템이 처음 시작되면, 말 그대로 마우스만으로는 아무것도 할 수 없다. 하지만 `Super + Space`를 눌러 Arch 메뉴를 표시할 수 있고, 여기에서 거의 모든 일을 할 수 있다.

하지만 Arch 메뉴는 대부분의 시간 동안 시스템을 조작하는 주요 수단이 될 의도조차 없다. 우리는 그보다 더 빨라질 수 있다! 가장 중요한 애플리케이션은 모두 개별 단축키에 직접 연결되어 있다. `Super + Return`으로 터미널을 시작하고 `Super + Shift + Return`으로 브라우저를 시작한다. 하나씩 차례로 해 보면 Hyprland 타일링의 마법이 작동하는 것을 볼 수 있다:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

그다음 `Super + J`를 누르면 나란히 배치하는 대신 위아래로 쌓을 수 있다:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J`를 다시 누르면 나란히 배치된 위치로 돌아간다. 그다음 브라우저에 있는 동안 `Super + Shift + Arrow Right`를 눌러 창을 서로 바꿔 보라.

이제 `Super + Ctrl + T`를 눌러 Activity 모니터를 시작해 보라. 플로팅 창으로 나타날 것이다. `Super + T`를 이용해 타일링할 수 있고 (다시 누르면 다시 플로팅으로 바뀐다). 이제 `Super + Shift + F`를 눌러 파일 관리자를 열어라. 깔끔한 4분할 배치가 완성될 것이다:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

활성화하려는 창 사이를 `Super + Arrow`로 이동한다. 이렇게 하면 포커스가 전환되고 커서가 새 애플리케이션의 중앙으로 이동한다.

`Super + Shift + 2`를 누르면 현재 포커스된 애플리케이션을 두 번째 작업 공간으로 이동시킨다. `Super + Shift + 1`은 다시 되돌린다. (그리고 `Super + Shift + Alt + 2`는 해당 작업 공간으로 전환하지 않고 현재 포커스된 애플리케이션을 두 번째 작업 공간으로 이동시킨다).

`Super`를 누른 채 마우스로 창을 클릭하면 창이 앉을 위치를 재배열할 수 있다. `Super`를 누른 채 마우스 오른쪽 버튼을 사용하면 창 크기를 자유롭게 조정할 수 있다.

창은 `Super + W` 또는 `Super + Q`로 닫는다 (그리고 모든 창은 `Ctrl + Alt + Delete`로 닫는다).

`Super + F`로 전체 화면으로 전환하거나, `Super + Alt + F`로 상단 바는 유지한 채 전체 너비로만 만들거나, `Super + Ctrl + F`로 창 안에서 전체 화면으로 만들 수도 있다 (YouTube에 좋다!).

### Dwindle vs 스크롤 레이아웃

Arch의 기본 레이아웃은 dwindle이라고 한다. 단일 작업 공간에서 연 모든 창을 항상 보이게 유지하며, 필요하면 크기를 줄여서라도 그렇게 한다.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

하지만 작업 공간을 창이 디스플레이의 보이는 가장자리를 넘어 나란히 줄지어 서는 스크롤 레이아웃으로 바꾸도록 선택할 수도 있다. `Super + L`을 이용해 단일 작업 공간을 이 레이아웃으로 바꾼다.

`Super + L`을 다시 누르면 작업 공간이 플로팅으로 바뀌어 창이 자유롭게 겹치고 직접 배치하게 되며, 세 번째로 누르면 dwindle로 돌아간다. `Super + Alt + L`은 반대 방향으로 순환한다. 어차피 떠 있는 창 — `Super + T`로 꺼낸 창이거나 항상 플로팅으로 열리는 앱 — 은 작업 공간이 타일링으로 돌아가도 계속 떠 있다. 상단 바는 현재 있는 작업 공간을 그 레이아웃으로 표시한다: dwindle은 사각형, 스크롤은 원, 플로팅은 삼각형이다. 그 표시를 클릭해도 레이아웃이 순환한다.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

선택은 작업 공간별로 이루어지며 유지된다. 그래서 작업 공간 1은 브라우징용으로 dwindle로, 작업 공간 2는 코드용으로 스크롤로 유지할 수 있으며, 재시작 후에도 그대로 돌아온다.

스크롤 레이아웃을 기본값으로 사용하고 싶다면 `~/.config/hypr/looknfeel.lua`에서 설정할 수 있다:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### 창 그룹화

창은 `Super + G`를 이용해 그룹화할 수 있다. 그룹에 들어가면, 그 상태에서 시작하는 모든 창은 그 그룹에 속하게 된다. `Super + Ctrl + Arrow Left/Right`를 이용해 이 그룹화된 창 사이를 이동하거나, `Super + Alt + 1/2/3/4`를 이용해 순서대로 그룹화된 창으로 직접 이동할 수 있다.

`Super + Alt + G`로 창을 그룹에서 꺼내거나 `Super + G`를 다시 눌러 그룹 전체를 해체할 수 있다. 마지막으로, `Super + Alt + Arrows`로 그룹 밖에 있는 창을 그룹 안으로 이동시킬 수 있다.

### 스크래치패드 작업 공간

마지막으로, Quake 콘솔처럼 현재 있는 작업 공간 위로 내려오는 특별한 스크래치패드 작업 공간이 있다. `Super + Grave` 또는 `Super + S`로 토글하고, `Super + Shift + Grave` 또는 `Super + Alt + S`를 이용해 거기에 창을 배치한다.

에이전트를 실행하는 터미널이나, 현재 작업 공간을 떠나지 않고 빠르게 상호작용하고 싶은 컨트롤에 특히 잘 작동한다. 창을 스크래치패드에서 이동시키려면 `Super + Shift + 1` 같은 단축키로 다른 작업 공간으로 직접 보낸다.

스크래치패드에 창이 하나만 있는 동안에는 화면 전체에 걸쳐 표시되지 않고 중앙 패널로 내려온다. 두 번째 앱을 거기에 넣으면 전체 너비로 돌아가 두 앱이 나란히 앉을 공간이 생긴다.

### 익숙해지는 데 시간이 좀 걸린다!

이런 식으로 데스크톱을 탐색하는 데 익숙해지는 데는 시간이 조금 걸리지만, 일단 익숙해지면 전통적인 마우스 중심 데스크톱 경험으로 돌아가기 어려울 것이다!
