# Benvenuto su Arch!

Arch è un desktop Linux essenziale costruito su Arch Linux, sul gestore di finestre affiancate [Hyprland](https://hypr.land/) e su [Quickshell](https://quickshell.org/). Offre un ambiente efficiente per le attività quotidiane, lo sviluppo software e la comunicazione.

Combina un desktop a finestre affiancate, un flusso di lavoro orientato alla tastiera e un insieme ridotto di applicazioni utili. Puoi aggiungere il software necessario dai repository Arch.

Il desktop mantiene le finestre affiancate e rende accessibili le azioni comuni dalla tastiera. Impostazioni, applicazioni e strumenti di sistema sono disponibili dal menu Arch.

Arch usa Linux e i normali file di configurazione Arch. Il terminale è a disposizione per i comandi e lo sviluppo, mentre il desktop offre controlli grafici per le impostazioni quotidiane.
