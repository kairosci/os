# Arch em...

### Chips Apple M1/M2

O [Asahi Alarm](https://asahi-alarm.org/) é uma versão do Arch para computadores Apple M1/M2 construída sobre o [Asahi Linux](https://asahilinux.org/). Com algum esforço, pode pôr o Arch a correr sobre ele. Veja [o guia feito pelos utilizadores](https://github.com/kairosci/os).

### Máquina virtual Apple

Também pode instalar o Arch dentro de uma VM Parallels. É um processo bastante trabalhoso, mas também há [um guia feito pelos utilizadores](https://github.com/kairosci/os) para isso.

### VirtualBox

O VirtualBox é um executor de VM popular. [Também pode correr o Arch dentro dele](https://github.com/kairosci/os). Mas o desempenho provavelmente não será grande coisa.

### VMware Workstation no Windows 11

Outro executor de VM popular para Windows. [O Arch também já foi configurado dentro dele](https://github.com/kairosci/os).

### Steam Deck

A Steam Deck corre Arch, o que significa que pode correr o Arch na sua Steam Deck. Altynbek Orumbayev tem [um script de configuração completo e uma explicação de como o fazer](https://github.com/aorumbayev/deckarchy). Que fixe que isso é!

### NixOS

O Arch é, na realidade, Arch + Hyprland, mas Henry Sipp [portou a essência da configuração para NixOS](https://github.com/henrysipp/arch-nix). Por isso, se caiu na pílula nix, aqui está um bom ponto de partida. Pode ou não acompanhar as últimas alterações do Arch, mas ainda assim é bastante fixe!

### Outra coisa qualquer!

Se estiver a tentar pôr o Arch a correr numa configuração que não é a predefinida, deve juntar-se ao canal #arch-on-other no [Discord da nossa comunidade](https://discord.gg/tXFUdasqhY).
