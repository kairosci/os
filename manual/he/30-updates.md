# עדכונים

Arch והחבילות שלכם נשמרות מעודכנות דרך _עדכון > Arch_ בתפריט Arch (`Super + Space`).

Arch עצמה מותקנת כחבילות pacman רגילות מ[מאגר החבילות של Arch](https://github.com/kairosci/arch), כך שעדכון מתקין את [גרסת Arch העדכנית ביותר](https://github.com/kairosci/arch), מריץ כל הגירה ממתינה כדי לסנכרן את המערכת שלכם עם העדכנית ביותר, ומעדכן את כל חבילות המערכת מ[מראת Arch של Arch](https://github.com/kairosci/arch) ומ[AUR](https://aur.archlinux.org/) (אם התקנתם חבילות AUR כלשהן).

כאשר יוצאות גרסאות חדשות, אייקון חץ עגול יופיע מימין לשעון שלכם. לחצו עליו ותהליך העדכון יתחיל.

![update-available](images/update-available.webp)

### ארבעה ערוצים

Arch מתעדכנת לאורך ארבעה ערוצים: יציב, RC, edge ו-dev. התקנות חדשות מתחילות בערוץ היציב, העוקב אחר [הגרסאות הרשמיות](https://github.com/kairosci/arch), וכן אחר [מראת Arch היציבה של Arch](https://github.com/kairosci/arch) המריצה חודש אחד מאחורי העדכנית ביותר, כך שנוכל לתפוס כל אי-תאימות חדשה הדורשת שינויי תצורה לפני שהם גורמים לבעיות לאנשים.

אבל אם תרצו לעזור לאתר את הבעיות הפוטנציאליות האלה, תוכלו לרוץ בערוץ edge. זה ישמור את חבילות Arch שלכם עוקבות אחר גרסאות הפיתוח העדכניות ביותר, ויאפשר לכם להתעדכן לחבילות Arch העדכניות ביותר ברגע שהן זמינות. עליכם לעשות זאת רק אם אתם מנוסים ב-Linux, ויודעים כיצד לשחזר מערכת שיש לה בעיות.

לפני כל גרסה עיקרית חדשה, נבצע אימות סופי באמצעות ערוץ RC. אם אתם מעוניינים לעזור בליטוש הסופי, בואו להסתובב ב-#arch-release-candidates ב-Discord.

לבסוף, יש ערוץ dev, המקשר את Arch ישירות לשכפול git של קוד המקור ב-`~/arch`, בשילוב עם חבילות edge. עליכם להשתמש בערוץ זה רק אם אתם משתמשי Linux מנוסים, העובדים ישירות על Arch, ומוכנים לסבול שברים.

תוכלו לעבור בין ערוצים באמצעות _עדכון > ערוץ_ מתפריט Arch (או `arch-channel-set` במסוף).

### עדכוני קושחה

החבילות שלכם אינן הדבר היחיד שמתיישן. מחשבים ניידים והתקנים היקפיים רבים שולחים קושחת BIOS, SSD ועגינה דרך שירות קושחת ספקי Linux, ו_עדכון > קושחה_ בתפריט Arch יביא ויתקין כל מה שהחומרה שלכם ממתינה לו. הוא מתקין את `fwupd` בפעם הראשונה שתפעילו אותו. הרבה קושחה ניתנת לכתיבה רק במהלך הפעלה מחדש, אז אל תופתעו אם תתבקשו לאחת.

### אזהרה לגבי עדכוני pacman/yay ישירים

אם אתם כבר מכירים את Arch, אולי תתפתו פשוט להריץ `pacman -Syu` או `yay -Syu` בעצמכם, אבל אם תעשו זאת, תפספסו את תמונת המצב, ההגירות ועדכוני התצורה ש-Arch מריצה יחד עם חבילות חדשות. לכן Arch תעצור בפועל שדרוג מערכת ישיר ותפנה אתכם ל-`archctl update` במקום זאת. (אם אתם באמת יודעים מה אתם עושים, השומר יאמר לכם כיצד לעקוף אותו עבור עסקה אחת.)

### החזרת עדכונים גרועים

אם אי פעם תהיה לכם בעיה לאחר ביצוע עדכון, תוכלו להחזיר את המערכת שלכם לתמונת המצב שצולמה לפני העדכון. פשוט הפעילו מחדש ובחרו את תמונת המצב בתפריט טעינת האתחול מזמן שלפני שהתחלתם את העדכון.

![bootloader](images/bootloader.webp)

אם איכשהו קבצי התצורה שלכם נפגמו, תוכלו גם לבצע התקנה מחדש של Arch באמצעות `arch reinstall` במסוף. זה יתקין מחדש את כל חבילות ברירת המחדל של Arch, ישים אתכם על יציב וישנמך כל חבילה שהיא חדשה מדי, ויאפס את כל קבצי התצורה. שימו לב שכל שינויי תצורת המשתמש שלכם לברירות המחדל של Arch יידרסו בעשותכם זאת!
