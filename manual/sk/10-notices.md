# Oznámenia

Pomocou klávesových skratiek pre oznámenia môžete rýchlo zobraziť dátum a čas, stav batérie a aktuálne počasie.

### Dátum a čas

`Super + Ctrl + Alt + T`

 ![notice-datetime](images/notice-datetime.webp)

### Počasie

`Super + Ctrl + Alt + W`

 ![notice-weather](images/notice-weather.webp)

Poloha sa zisťuje z vašej IP adresy, čo je zvyčajne dostatočne blízko, ale nie vždy. Môžete ju upresniť pomocou `arch weather location --set Malibu` alebo byť úplne presní pridaním súradníc: `arch weather location --set Malibu 34.0259,-118.7798`. Samotné spustenie `arch weather location` vám ukáže, kde si systém myslí, že ste, a `--clear` vás vráti k automatickému zisťovaniu.

`Super + Ctrl + Alt + B`
