# Arch บน...

### ชิป Apple M1/M2

[Asahi Alarm](https://asahi-alarm.org/) เป็น Arch เวอร์ชันสำหรับคอมพิวเตอร์ Apple M1/M2 ที่สร้างบน [Asahi Linux](https://asahilinux.org/) คุณสามารถทำให้ Arch รันบนนั้นได้ด้วยความพยายามบางส่วน ดู [คู่มือที่ผู้ใช้จัดทำ](https://github.com/kairosci/arch)

### เครื่องเสมือน Apple

คุณยังติดตั้ง Arch ภายใน VM Parallels ได้ เป็นกระบวนการที่ค่อนข้างยุ่งยาก แต่มี [คู่มือที่ผู้ใช้จัดทำ](https://github.com/kairosci/arch) สำหรับเรื่องนั้นเช่นกัน

### VirtualBox

VirtualBox เป็นตัวรัน VM ยอดนิยม [คุณสามารถรัน Arch ข้างในนั้นได้เช่นกัน](https://github.com/kairosci/arch) แต่ประสิทธิภาพอาจไม่ดีนัก

### VMware Workstation บน Windows 11

ตัวรัน VM ยอดนิยมอีกตัวสำหรับ Windows [Arch ถูกตั้งค่าภายในนั้นเช่นกัน](https://github.com/kairosci/arch)

### Steam Deck

Steam Deck รันบน Arch ซึ่งหมายความว่าคุณสามารถรัน Arch บน Steam Deck ของคุณได้ Altynbek Orumbayev มี [สคริปต์ตั้งค่าเต็มรูปแบบและคำอธิบายวิธีทำ](https://github.com/aorumbayev/deckarchy) เท่แค่ไหนล่ะ!

### NixOS

Arch จริง ๆ คือ Arch + Hyprland แต่ Henry Sipp ได้ [ย้ายแก่นของการตั้งค่าไปยัง NixOS](https://github.com/henrysipp/arch-nix) ดังนั้นถ้าคุณถูก nix-pill แล้ว นี่คือจุดเริ่มต้นที่ดี มันอาจหรืออาจไม่อัปเดตตามการเปลี่ยนแปลงล่าสุดของ Arch แต่ก็ค่อนข้างเท่อยู่ดี!

### อย่างอื่น!

ถ้าคุณกำลังพยายามทำให้ Arch รันบนการกำหนดค่าที่ไม่ใช่ค่าเริ่มต้น คุณควรเข้าร่วมช่อง #arch-on-other บน [Discord ชุมชนของเรา](https://discord.gg/tXFUdasqhY)
