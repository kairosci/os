# 更新

Arch とあなたのパッケージは、Arch メニュー（`Super + Space`）の _更新 > Arch_ 経由で最新に保たれます。

Arch 自体は [Arch Package Repository](https://github.com/kairosci/arch) からの通常の pacman パッケージとしてインストールされているため、更新では [最新の Arch リリース](https://github.com/kairosci/arch) がインストールされ、あなたのシステムを最新と同期させるために保留中のマイグレーションがすべて実行され、すべてのシステムパッケージが [Arch Arch Mirror](https://github.com/kairosci/arch) と [AUR](https://aur.archlinux.org/)（AUR パッケージをインストールしている場合）から更新されます。

新しいリリースが作成されると、時計の右側に円形の矢印アイコンが現れます。それをクリックすると更新プロセスが開始します。

![update-available](images/update-available.webp)

### 4つのチャネル

Arch は stable、RC、edge、dev の4つのチャネルに沿って更新されます。新規インストールは stable チャネルから始まります。これは [公式リリース](https://github.com/kairosci/arch) を追跡するとともに、1か月遅れの [stable Arch Arch mirror](https://github.com/kairosci/arch) を追跡します。そのため、設定変更を必要とする新たな非互換性を、問題を引き起こす前にキャッチできます。

しかし、それらの潜在的な問題を見つける手助けをしたいなら、edge チャネルで運用できます。それにより Arch パッケージは最新の開発ビルドを追跡しし続け、Arch パッケージが利用可能になり次第最新へ更新できます。あなたが Linux に経験があり、問題のあるシステムを復旧できる場合にのみそうしてください。

大きな新リリースの前には、RC チャネルを使って最終検証を行います。最終的な仕上げに興味があるなら、Discord の #arch-release-candidates で一緒に過ごしてください。

最後に、dev チャネルがあります。これは Arch を、edge パッケージと組み合わせて、`~/arch` にあるソースコードの git チェックアウトに直接リンクします。あなたが熟練した Linux ユーザーで、Arch そのもの上で作業し、破損を許容する意思がある場合にのみこのチャネルを使ってください。

チャネルの切り替えは Arch メニューの _更新 > Channel_ で（またはターミナルの `arch-channel-set` で）行えます。

### ファームウェア更新

陳腐化するのはあなたのパッケージだけではありません。多くのノートPCと周辺機器は Linux Vendor Firmware Service を通じて BIOS、SSD、ドックのファームウェアを出荷しており、Arch メニューの _更新 > Firmware_ は、あなたのハードウェアが待っているものを取得してインストールします。初めて実行したときに `fwupd` がインストールされます。多くのファームウェアは再起動中しか書き込めないため、再起動を求められても驚かないでください。

### 直接 pacman/yay で更新することへの警告

すでに Arch に馴染みがあると、自分で `pacman -Syu` や `yay -Syu` を実行したくなるかもしれませんが、それでは、新しいパッケージとともに Arch が実行するスナップショット、マイグレーション、設定更新を見逃してしまいます。そのため Arch は直接システムアップグレードを止めて、代わりに `archctl update` に誘導します。（本当に何をしているか分かっている場合、ガードは単一のトランザクションでそれをバイパスする方法を教えてくれます。）

### 悪い更新をロールバックする

更新を行った後にいつか問題が起こった場合、更新前に撮られたスナップショットにあなたのシステムをロールバックできます。ただ再起動し、ブートローディングメニューで、あなたが更新を開始する前のスナップショットを選んでください。

![bootloader](images/bootloader.webp)

もし何らかで設定ファイルが壊れてしまった場合は、ターミナルの `arch reinstall` で Arch の再インストールもできます。これによりすべてのデフォルトの Arch パッケージが再インストールされ、stable になって新しすぎるパッケージはダウングレードされ、すべての設定ファイルがリセットされます。Arch のデフォルトに対するあなたのユーザー設定の変更は、これで上書きされてしまう点に注意してください！
